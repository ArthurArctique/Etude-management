# Fichiers de travail

Un dossier par {{UNITE}}, nommé par son code officiel s'il existe (sinon un nom court et stable) : `{{TRAVAIL}}/<CODE>/`.

## Organisation d'un dossier

```text
<CODE>/
├── README.md        nom complet, alias, liens utiles (facultatif)
├── <ACTIVITÉ>/<ACTIVITÉ><NN>/   une séance numérotée sur deux chiffres
├── Ressources/      documents transversaux, indexés en entier
└── _temp/           fichiers jetables
```

Activités prévues : {{ACTIVITES}}. Exemple : `{{ACTIVITE_EXEMPLE}}`. Ne créer que les sous-dossiers réellement utiles et conserver les noms de fichiers transmis.

Les supports de cours (diaporamas, polycopiés, chapitres, articles) ne vont pas ici : ils se rangent dans Zotero, en fichiers liés.
