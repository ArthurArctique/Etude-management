# Tâches à faire plus tard

Ce dossier conserve les sujets volontairement reportés, pour qu'un agent puisse les reprendre sans dépendre de l'historique des conversations.

Une fiche de tâche indique le contexte, ce qui a déjà été vérifié, les décisions restant à prendre, les autorisations nécessaires et les critères de fin. Sa présence ici n'est jamais une autorisation d'agir.

## États possibles

- `reportée` : conservée pour plus tard, sans action attendue maintenant ;
- `à décider` : une décision de l'utilisateur est nécessaire avant de poursuivre ;
- `prête` : la méthode est définie, l'utilisateur doit encore demander son exécution ;
- `en cours` : reprise explicitement demandée ;
- `terminée` : résultat vérifié et livré.
